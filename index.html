Setup & test guide (Cloudflare free plan)
  1. Go to Cloudflare Dashboard → Workers & Pages → Create and pick the "Hello World" template (the free plan is enough for testing).
  2. Replace the generated code with the Worker code below and click Deploy.
  3. Copy your *.workers.dev URL, paste it above, tap Save, then Test (it checks the Worker's /health route).
  4. Test with a public, direct media URL (a plain .mp4/.m4a link you own or are authorized to use). Paste it in "Video Link / URL" and tap Load.

What to expect: public direct files are fetched through the Worker and transcribed with your own Groq key. Private or sign-in-only links, platform pages (Instagram/TikTok/YouTube watch links), files over 25MB, and unreachable hosts all fail with a clear message — no silent retries. For platform reels, download the video to your device and use "Choose Video from Phone" (unchanged).

Sample Worker limits: only http(s) sources, 25MB max, no secrets stored, CORS enabled for this app. The free Workers plan is fine for testing; a paid plan only matters later if you proxy large volumes.
